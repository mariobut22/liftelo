# Liftelo – službeni logo (koncept 1)

Odabrao Mario 2026-11-02: crni "L" koji je okno lifta s malom kabinom u gornjem desnom kutu.

## Datoteke
| Datoteka | Za što |
|---|---|
| `liftelo-lockup.svg` / `.pdf` | Znak + riječ "Liftelo", tamna verzija (za svijetle pozadine) |
| `liftelo-lockup-white.svg` / `.pdf` | Isto, bijela verzija (za tamne pozadine; PDF je na prozirnoj pozadini pa se na bijelom ne vidi) |
| `liftelo-icon.svg` / `.pdf` | Samo znak, tamna verzija |
| `liftelo-icon-white.svg` / `.pdf` | Samo znak, bijela verzija |
| `build-logo.py` | Skripta kojom su SVG-ovi generirani (nije potrebna za korištenje) |

- Sve je vektor, a **tekst je pretvoren u obrise** (font se ne treba instalirati; Illustrator ga otvara kao obične oblike).
- Boja: tamna `#18181b`, bijela `#ffffff`. Pozadina je prozirna.
- Riječ je u fontu **Inter Bold (700)**, razmak slova -0,01 em (Inter je besplatan, SIL Open Font License).
- Znak je nacrtan u kvadratu 64×64 (prazan rub je namjeran, to je zaštitni prostor); lockup je 194,91×64.

## Napomene
- Stranica trenutno ispisuje riječ "Liftelo" sistemskim fontom (SF na Macu), pa se malo razlikuje od ovog lockupa u Interu. Ako želiš potpuno isto, riječ na sajtu možemo prebaciti na Inter.
- Favicon na sajtu je još stari (kocka s L).
- Provjera sličnosti sa zaštićenim znakovima nije rađena.
