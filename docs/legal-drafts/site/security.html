Security

Version: draft of 2026-11-06 · Effective: [[DATUM_SNAGA: effective date]]

We list only what we actually do. We do not claim certifications or guarantees we cannot back up.

What we do

  • Separation between companies. Every record belongs to one company and every database query filters by company. We check this with a static analysis tool before each server change and with an automated test using two companies (91 checks).
  • Role-based access. Admin, technician and viewer have different rights; a viewer cannot change data.
  • Passwords are stored only as a hash (bcrypt), never in readable form.
  • Sessions. Sign-in uses a cookie that JavaScript cannot read (HttpOnly) and, in production, is sent only over an encrypted connection (Secure).
  • Private files. Photos, signatures, attachments and logos are available only to signed-in users of the owning company; files that are not images or PDFs are downloaded rather than opened in the browser.
  • Encryption in transit. The app and the website use HTTPS.
  • Action log. We record important actions (sign-ins, administrative changes). Our staff's actions on companies require a reason and re-entering a password, and are logged.
  • Historical records. Service records (visits, interventions) are append-only.
  • Internal review. In November 2026 we carried out an internal review of company separation and access control across the whole server code and fixed the findings. This is an internal review, not an independent audit.
  • Backups: [[BACKUP_OPIS: description of production backups]].

What we do not promise

  • We hold no certifications (e.g. ISO 27001, SOC 2).
  • We offer no SLA or guaranteed availability. The service runs on a single server without redundancy.
  • Hosting region: [[REGIJA: server region/country]]. We do not promise that all data stays exclusively in the EU, because some suppliers (see Subprocessors) may process data elsewhere.

Reporting a vulnerability or breach

If you found a security problem, write to [[EMAIL_SIGURNOST: security e-mail]]. Describe what you found and how to reproduce it; please do not access other people's data. We report data breaches to customers without undue delay.
